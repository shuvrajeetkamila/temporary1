# Data sources and authority gate

**World epoch:** not yet selected. **Authoritative coverage state:** blocked pending acquisition and verification of legally redistributable source datasets.

No OpenStreetMap, imagery, DEM, bathymetry, boundary, road, building, airport, port, transit, or landmark data is currently shipped in this foundation. Thus no attribution is currently owed for a shipped third-party data derivative.

Before making any claim of country coverage, this project must record for each accepted source: dataset/version, canonical URL, acquisition date, license text, scope, source SHA-256, processing command/version, resulting compiled bundle hashes, and any required attribution. Google Maps/Earth/Street View, proprietary tiles, commercial models, and unverified public-viewable content are explicitly prohibited.
