# Data sources — fresh standalone build

This initial standalone EXE uses an original, deterministic island contour and procedural terrain in a local metre coordinate frame. It has **no downloaded geographic dataset** and must not be presented as an authoritative geographic representation.

The next data milestone should add a reproducible open-data pipeline (for example OSM geometry and an openly redistributable elevation source), source checksums, conversion metadata, and the required attribution. No OpenStreetMap-derived geometry is currently present, so the executable does not make an OSM-data claim.
